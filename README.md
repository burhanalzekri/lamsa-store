# لمسة — متجر أزياء عربي قابل للتثبيت

مشروع متجر عربي باتجاه RTL مبني على React + Vite + TypeScript وExpress/tRPC وقاعدة MySQL من خلال Drizzle، ومهيأ كتطبيق ويب تقدمي قابل للتثبيت من متصفح Android المتوافق. هذه الحزمة مصدر المشروع وليست APK. تعتمد على خدمات Manus OAuth وقاعدة البيانات والتخزين؛ لم تُضمّن أسرار أو بيانات عملاء.

## وظائف المتجر والإدارة

الواجهة العامة تعرض المنتجات النشطة وأسعارها وألوانها ومخزونها الفعلي. تسجيل Manus مطلوب لإضافة منتج إلى الحقيبة أو لإرسال طلب. التحقق من السعر والتوفر وإنشاء الطلب وحجز المخزون يتم في الخادم ضمن معاملة قاعدة بيانات. لوحة الإدارة تحت `/admin` متاحة لدور `admin` فقط، وتضم إدارة المنتجات والتكلفة، أرصدة الألوان، الطلبات، حسابات المستخدمين وصلاحياتهم، والتقارير الشهرية.

حالة الدفع يدوِّنها المشرف يدويًا؛ لا توجد بوابة دفع إلكترونية موصولة. التقرير يعرض الربح الإجمالي من المنتجات المدفوعة بعد خصم تكلفة شرائها المسجلة وقت الطلب، ولا يشمل المصاريف التشغيلية أو الرسوم/الضرائب/الشحن أو المرتجعات الجزئية. الأرشفة تخفي المنتج لكنها لا تحذف سجلًا مرتبطًا بطلب سابق.

## إعداد أول مشرف

يُحفظ بريد المشرف الأول خارج ملفات المصدر عبر المتغير المحمي `LAMSA_ADMIN_EMAIL` في إعدادات المشروع. يسجل صاحب هذا البريد الدخول بحساب Manus، ويتعرف النظام على الحساب ويمنحه دور `admin`. لا تُمنح صلاحية الإدارة لأول مستخدم تلقائيًا ولا يغيّر المشرف دور حسابه. لا تضع البريد أو أي قيمة سرية داخل المستودع.

## التثبيت والتشغيل

يتطلب المشروع Node.js متوافقًا وpnpm 10 وبيئة Manus مجهزة لـOAuth/MySQL. بعد استعادة المصدر:

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm build
```

تتطلب التهيئة أن تكون خدمة Manus و`DATABASE_URL` متاحة في بيئة الخادم. لإنشاء مخطط قاعدة المتجر في البيئة المصرّح بها:

```bash
pnpm db:migrate
```

قاعدة المشروع المُدارة مشتركة بين المعاينة والإنتاج؛ راجع SQL قبل migrations. يحتوي `drizzle/0001_bright_bloodstorm.sql` على جداول المتجر الأربع الإضافية. تبدأ المنتجات والطلبات فارغة وتُدخل المنتجات الحقيقية من لوحة الإدارة. لا تستعمل `db:push` على قاعدة الإنتاج دون مراجعة وتفويض.

## الصور والملفات

قد تستخدم صور الحملة مسارات التخزين `/manus-storage/...` التابعة لخدمة المشروع. عند نقل المصدر إلى مشروع Manus آخر، انقل الصور إلى تخزين ذلك المشروع وحدّث روابطها من لوحة المنتجات. تقبل صور المنتجات روابط `https://` أو مسارات `/manus-storage/` فقط.

## التنبيهات والمسارات

تظهر نتائج العمليات في إشعار موحّد؛ تُحوّل أخطاء الخادم الداخلية إلى رسائل عربية عامة ولا تعرض stack أو استعلامات قاعدة البيانات. المسار غير المعروف يعرض صفحة 404 مخصصة. عند إضافة صفحة حدّث `client/public/manus-routes.json`.

## أوامر القالب

- `pnpm dev`: خادم تطوير يلتزم بـ`PORT` (افتراضيًا 3000).
- `pnpm build` و`pnpm start`: بناء وتشغيل `dist/index.js` و`dist/public/`.
- `pnpm db:migrate`: تطبيق migrations المثبتة.
- `pnpm check` و`pnpm test`: فحص الأنواع والاختبارات.

رقم التواصل العام للمتجر غير مضبوط بعد؛ لم نضع بريدًا أو هاتفًا افتراضيًا قد لا يكون ملكًا للمتجر. أضف الرقم المعتمد بعد تزويد المشروع به إذا رغبت في إظهاره على الواجهة.
